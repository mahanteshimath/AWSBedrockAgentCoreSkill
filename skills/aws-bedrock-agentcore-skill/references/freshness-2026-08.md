## Minimum answer changes for every area

1. Start by checking whether the user's request fits AgentCore harness before defaulting to custom Runtime.
2. If the user asks for “Bedrock Agents,” clarify whether they mean Agents Classic or AgentCore; for new customers after 2026-07-30, route to AgentCore.
3. For production Runtime, ask whether they need serverless isolation, direct code deploy, or Instances capacity providers/GPU/long sessions.
4. For Gateway designs, add rate limits, source validation, and policy/guardrail enforcement as production defaults.
5. For RAG, compare classic Knowledge Bases with AgentCore Managed Knowledge Base instead of assuming only one KB service.
6. For observability, include unified span destination behavior and `ActiveSessionCount` alarms.
7. For rollout, treat Evaluations, Recommendations, and A/B Testing as GA; label Failure Insights Preview.
